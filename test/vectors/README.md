# Test vectors

Generated by `make vectors` (`cerberus-cli vectors`). Do not edit by hand.
`make vectors-check` regenerates them in `build/` and fails if they differ.

- `manifest.toml` lists every image, the expected result (`ok` or an error
  name) and the step of the verifier check order that should reject it.
- Images are signed with a fixed, **public** test key. Its public key and the
  SHA-256 of that key are in the manifest. It is not a secret and must never
  be used for anything real.
- Valid images: `valid_*`. Rejections: `bad_*` (corrupted) and `forged_*`
  (header edited with a fresh CRC but the old signature).
- Rollback is a policy check against the hardware counter, so it is not a
  property of one image. Use `valid_app_secver1/2` with different counter
  values, and `forged_secver` to check that the signature catches a
  lowered version.
